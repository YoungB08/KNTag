KNCMS – Tài liệu sử dụng

PHP 8+ PDO Prepared Statements XSS Escape Facade Pattern

Mục tiêu kiến trúc

KNCMS là một Facade (cổng gọi) để giữ nguyên “tên hàm” quen thuộc, nhưng toàn bộ logic được tách theo module chức năng.

KNCMS::getIp()  -> Network::getIp()
KNCMS::query()  -> DB::query()
KNCMS::e()      -> Security::e()
KNCMS::capbac() -> UserHelper::capbac()

Cấu trúc thư mục

src/KNCMS/
  KNCMS.php                 (Facade)
  Core/Env.php              (.env loader)
  Core/Security.php         (XSS + CSRF)
  Core/Session.php          (session hardening)
  Database/DB.php           (PDO)
  Network/Network.php       (IP + curl)
  User/UserHelper.php       (business helpers)
  Utils/Text.php            (slug)
  Utils/Formatter.php       (format)

Cài đặt

  1. Copy .env.example thành .env và điền DB credentials.
  2. Chạy lệnh trong thư mục project:
composer install
composer dump-autoload

Khởi tạo (boot)

Trong entrypoint (ví dụ public/index.php):

<?php
require __DIR__ . '/../vendor/autoload.php';

\KNCMS\KNCMS::boot(dirname(__DIR__));

Boot sẽ:

  • Start session (hardening)
  • Load .env
  • Kết nối PDO (utf8mb4, ERRMODE_EXCEPTION, disable emulate prepares)

Network

KNCMS::getIp()

$ip = \KNCMS\KNCMS::getIp();

KNCMS::curl_get($url)

$html = \KNCMS\KNCMS::curl_get("https://example.com");

Database

Luôn dùng prepared statements (params) để chống SQLi.

KNCMS::query($sql, $params)

$stmt = \KNCMS\KNCMS::query(
  "SELECT * FROM users WHERE id = :id",
  ["id" => 1]
);

KNCMS::get_row($sql, $params)

$user = \KNCMS\KNCMS::get_row(
  "SELECT id,email FROM users WHERE email = :e LIMIT 1",
  ["e" => "a@b.com"]
);

KNCMS::get_list($sql, $params)

$rows = \KNCMS\KNCMS::get_list(
  "SELECT id,email FROM users ORDER BY id DESC LIMIT 10"
);

Security

XSS Escape

echo \KNCMS\KNCMS::e($user["email"]);

CSRF (cho form POST)

<input type="hidden" name="_csrf" value="<?= \KNCMS\KNCMS::csrfToken() ?>">
// verify in POST handler:
if (!\KNCMS\KNCMS::verifyCsrf($_POST["_csrf"] ?? null)) {
  http_response_code(403);
  exit("CSRF");
}

User

KNCMS::capbac($level)

$label = \KNCMS\KNCMS::capbac(2); // Nhân viên

Gợi ý mở rộng

  • Thêm Auth/Auth.php (login/register) theo pattern tương tự, rồi expose qua KNCMS::login(), KNCMS::register().
  • Thêm RateLimit/RateLimiter.php và map KNCMS::allow().
  • Thêm QueryBuilder/ORM nếu cần.

Tài liệu này đi kèm bộ folder mẫu. Bạn có thể tùy biến namespace và mapping trong composer.json.
